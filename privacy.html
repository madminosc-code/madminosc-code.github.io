renderfarm 개인정보처리방침 (Privacy Policy)

최종 수정: 2026-10-23

1. 누가 쓰는가

renderfarm은 운영자 개인이 자신의 컴퓨터들 사이에서 영상 렌더 작업 파일을 옮기는 데만 쓰는 도구입니다. 운영자 본인 소유의 구글 계정 외에는 사용하지 않습니다.

2. 접근하는 데이터

로그인한 계정의 Google Drive 안 renderfarm 폴더에 있는 파일(영상 프로젝트 파일, 완성 영상, 렌더 기록)만 읽고, 쓰고, 지웁니다. 다른 파일, 이메일, 연락처, 프로필 정보는 사용하지 않습니다.

3. 저장과 공유

데이터는 해당 계정의 Google Drive와 운영자 본인의 컴퓨터에만 저장됩니다. 운영자 외의 누구에게도 판매, 공유, 전송하지 않으며, 광고나 분석에 쓰지 않습니다.

4. 삭제

작업이 끝난 파일은 도구가 Drive에서 바로 지웁니다. 계정의 Google 보안 설정(타사 앱 액세스)에서 접근 권한을 언제든 취소할 수 있습니다.

5. Google API 데이터 사용

renderfarm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to transfer the owner's own files between the owner's own computers and is never shared with third parties.

6. 문의

구글 로그인 동의 화면에 표시되는 지원 이메일로 문의할 수 있습니다.
